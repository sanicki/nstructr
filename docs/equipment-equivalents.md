# Equipment equivalents (Sep 2026)

For every library exercise: established versions of the same exercise with the other equipment the library uses
(the AI prompt's headings: no equipment, band, door anchor, dumbbell, barbell, kettlebell, chair, bench, wall, step, towel; a mat
doesn't count). "Established" means described by a reputable source under that name, not invented here.

- ✅ added (batch 1, or batch 2 where marked; cited in each file's `source`)
- ⏳ found, not added yet: a later batch (each one needs its own poses, props, words and source, and must pass the
  animation checks, the range of motion and the duplicate check)
- — nothing established found for the other equipment

For a new exercise, the same research: `.claude/skills/exercise-research/SKILL.md` (`node tools/research.cjs report
<id>` lists its names, versions in the library and the equipment with none yet; submission PRs include that list).

## Foam roller (added Sep 2026, batch 17)

| Library exercise | Equivalents |
|---|---|
| Foam Roller Calf Roll, Hamstring Roll, Quad Roll, Upper Back Roll, Glute Roll, IT Band Roll, Lat Roll | — (the same rolling is done with a massage ball or a roller stick, neither of them library equipment; the stretches for the same muscles are already in the library) |

Names: NASM calls them "Foam Roll Calves" and so on ([NASM Exercise Library](https://www.nasm.org/resource-center/exercise-library/foam-roll-calves)); rolling the upper back is also "thoracic spine" rolling; the figure-four glute roll is NASM's "Foam Roll Piriformis", and the lat roll its "Foam Roll Latissimus Dorsi". "Foam Roller Thoracic Extension" is a different exercise (arching back over a still roller), so it isn't an other name.
