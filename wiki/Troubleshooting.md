# Troubleshooting

[← User guide](Home.md)

**I can't hear anything.**
Check **Settings → Sound** is Voice or Coach, the phone isn't on silent, and media volume is up. The voice is the
phone's text-to-speech: in Android, *Settings → Accessibility → Text-to-speech* should have an engine and a
voice installed. Some apps' built-in browsers (opening the link from a chat app) can't speak: open it in Chrome.

**It won't go full screen.**
Check **Settings → Full screen**. Chrome shows its own "exit full screen" notice, which the app can't move.
Installing the app avoids both.

**My workouts disappeared.**
Browsers can clear a website's data when the phone is low on space, or when you clear browsing data. Restore
your latest backup with **Settings → Import everything**. Installing the app makes this much less likely.

**A shared link says it's damaged or incomplete.**
The link was cut short (some apps shorten long messages). Ask for it again, or ask for the file (**As a file**).

**A shared link opens but some exercises are missing.**
It was made with a newer library. Open the app while online so it updates, then open the link again.

**Create with AI opened the AI app with an empty message.**
The instructions are always copied too: paste them into the chat (long-press → Paste). Some installed AI apps
ignore the prefilled message that their website accepts.

**The AI's answer won't import.**
Make sure you copied all of it. Ask the AI to "answer with only the JSON file", then paste again.

**The figure does something odd.**
It's a simplified figure; the written steps are the reference. If an exercise looks wrong, please report it
(see the [README](../README.md)).
